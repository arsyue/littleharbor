# Little Harbor

An English-learning aquarium game. Source editing, asset preparation, Godot exports, and verification run in the cloud. No local engine installation is required.

The current public game is preserved while the Godot aquarium is developed.

Original site: https://little-harbor-english-aquarium.abloom-chub-6743.chatgpt.site

## Rebuild direction

- A real 3D aquarium rendered by Godot, with continuous swimming, articulated fins and tails, and smooth steering.
- Keep the English-first dialogue, voice input with typing fallback, coin economy, fish collection, decoration purchases, tank upgrades, and saved progress.
- Web exports built and checked using GitHub Actions.
