# Little Harbor town artwork

Thirteen independent ImageGen assets for the public Little Harbor game. Original transparent PNG artwork and generation prompts live in this cloud repository. The cloud build packages optimized transparent WebP files and computes sprite atlas bounds; development and builds run on GitHub-hosted infrastructure.

The town uses depth-sorted buildings, foliage, fountain and characters, directional explorer animation and soft occlusion when scenery covers the player. Original location coordinates, walking paths, saved progress and English-learning stories are preserved.

See `manifest.json` for the prompt set and `source/` for original assets. Generated local image files are temporary upload staging only, as authorized by the project owner.
